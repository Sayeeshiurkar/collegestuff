
# Student Attendance Manager

A full-stack student attendance management application.

## Technologies Used

- React
- Vite
- Node.js
- Express.js
- MongoDB

## Project Structure

- frontend/ - Frontend application
- backend/ - Backend API

## Prerequisites

- Node.js and npm
- MongoDB, if using the local database configuration

## How to Run

### Backend

Open a terminal in the project folder and run:

    cd backend
    npm install
    npm start

### Frontend

Open a second terminal in the project folder and run:

    cd frontend
    npm install
    npm run dev

Open the local URL printed by Vite in the terminal.

## Note

The frontend and backend run separately. MongoDB must be available for database operations.
